# SUNBIRD Power Solutions Website

A modern, responsive corporate website for **SUNBIRD Power Solutions**, focused on showcasing solar power products, renewable energy services, and industrial power solutions.

---

##  Project Overview

SUNBIRD Power Solutions is a professional solar and energy solutions company website designed to:

* Showcase solar power products and services
* Highlight industrial and commercial energy solutions
* Build trust through professional branding
* Generate leads through contact forms and inquiry sections
* Provide detailed information about solar infrastructure solutions

---

## Features

### Frontend Features:

* Modern responsive design for desktop, tablet, and mobile
* Smooth animations using Framer Motion
* SEO-friendly architecture with Next.js
* Fast-loading optimized images
* Mobile navigation menu
* Hero section for branding
* Services showcase
* Product categories
* Leadership/About section
* Contact form integration
* Professional industrial design theme

### Technical Features:

* Built with Next.js
* TypeScript support
* Tailwind CSS styling
* Component-based architecture
* Reusable UI sections
* Vercel-ready deployment
* GitHub integration for CI/CD

* **Framework:** Next.js

## Installation & Setup

### Clone Repository

```bash
git clone https://github.com/yourusername/sunbird-power.git
cd sunbird-power
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

### Open in Browser

```bash
http://localhost:3000
```
